# QA Portfolio

A responsive interactive portfolio built with plain HTML, CSS and JavaScript.

## Run locally

1. Unzip the folder.
2. Open `index.html` in your browser.

For a better development workflow in VS Code, install Live Server and open `index.html` with Live Server.

## Personalize before publishing

In `index.html`:
- Update education wording/dates if needed.
- Add real GitHub/live-demo links to your projects.

## Deploy

This is a static website and can be deployed to GitHub Pages, Netlify or Vercel without a build step.
