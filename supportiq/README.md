# SupportIQ

SupportIQ is an interactive IT support and root-cause analysis portfolio project.

## What it demonstrates
- Tier 1 / Tier 2 troubleshooting decision trees
- Hypothesis scoring as evidence is collected
- Root-cause analysis with confidence
- P1–P4 priority and severity
- Security and infrastructure escalation decisions
- Incident history stored in the browser
- RCA analytics
- ITIL-style incident summaries
- Responsive and keyboard-friendly interaction

## Scenario domains
Network, VPN, identity, Microsoft 365, endpoint performance, printers, security, OneDrive, applications, Teams, Azure and storage.

## Run through the portfolio repository
From the repository root:

```bash
npm install
npm run dev
```

Then open the SupportIQ page served by Vite.

## Production URL after merge
`/JoshuaNPortfolio/supportiq/`

> Portfolio/training demo only. SupportIQ does not execute administrative changes or replace an organization's approved IT/security procedures.
